# Image Upload Instructions

## Required Images

Please upload the following images to their respective folders:

### /couple/
- **couple-main.jpeg** (or .jpg/.png) - Main couple photo for hero section
- **bride.jpg** (optional) - Individual bride photo
- **groom.jpg** (optional) - Individual groom photo

### /gallery/
Upload multiple photos here (name them sequentially):
- **gallery-1.jpeg** (or .jpg)
- **gallery-2.jpeg** (or .jpg)
- **gallery-3.jpeg** (or .jpg)
- **gallery-4.jpeg** (or .jpg)
- ... (add as many as needed)

### /events/
- **mehendi.jpeg** (or .jpg) - Mehendi event photo
- **haldi.jpeg** (or .jpg) - Haldi event photo
- **sangeet.jpeg** (or .jpg) - Sangeet event photo
- **wedding.jpeg** (or .jpg) - Wedding event photo

## Image Requirements
- Recommended format: JPG or PNG
- Recommended size: 1920x1080px or larger
- File size: Optimize images before upload (keep under 2MB each)

## How to Replace Images
1. Simply replace the placeholder files in these folders
2. Keep the same file names
3. No code changes needed
